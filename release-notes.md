# Holder Catalogue 0.1.0

First release of the Windows desktop app.

- **Catalogue** of HSK-A63 holders on site and available to buy (88 articles: 54 from the hyperMILL tool database, 34 MAPAL UNIQ), with maker data, gauge length ruler, nose Ø, provenance and open issues.
- **Count mode** for the tool crib: pick a location, step through holders, book counts. Every change is a dated stock transaction with a name and reference.
- **Tally** by type, maker, clamp Ø and location, with counted vs. unverified progress; CSV and Excel export.
- **Issues** raised between hyperMILL and maker data, closed with a name and what was done; hyperMILL write-back list.
- **hyperMILL import** of the tool-database HTML report (preview first; never deletes).
- **Vendor sync** on command (HAIMER, MAPAL, KEMMLER; manual import route for CERATIZIT, SANDVIK, CUTWEL) with approve-before-write.
- **Want list → RFQ** export by maker; **serialised holders** with runout checks and quarantine.
- **Share on network** so shop-floor tablets can count in a browser (PIN sign-in); daily automatic backups.

Install: run `Holder-Catalogue-Setup-0.1.0.exe` (no admin rights needed). Data lives in `C:\Holder Catalogue`.
